Detailed Description

Configuration options for FracturedJson formatting.

FracturedJson intelligently chooses between different layout strategies (inline, compact multiline, table, expanded) based on content complexity, length, and structure similarity.

◆ enable_table_format

bool simdjson::fractured_json_options::enable_table_format = true

Enable tabular formatting for arrays of similar objects or arrays (default: true).

When enabled, the rows of such an array are written one per line with their columns aligned. Rows need not have identical keys: columns are ordered by the first occurrence of each key, and a row missing a key gets blank space in that column.
